# DVT Command — Dryer Vent Tech of Nashville

Phone-first business app built by Transcenlutions LLC for Dryer Vent Tech (Nashville, TN).

- **Customer website:** https://transcenlutions25.github.io/dryer-vent-tech-app/
- **Owner command app:** https://transcenlutions25.github.io/dryer-vent-tech-app/app/ (Chrome on Android → ⋮ → "Add to Home screen")
- **Jay** (`jay.js`) — built-in assistant on both: customer questions about dryer vents, fire safety, codes and booking; in the app also live business numbers, how-to help, and the Company Direction interview (Owner → Direction). No AI fees; works offline.
- **Owner panel PIN (sample):** 1234 — change in Owner → Settings
- `index.html` — customer website
- `app/index.html` — the command app (jobs, safety reports, CRM, invoices, crew & payroll, tax prep). Data saves on the device; use Owner → Settings → Download backup.
- `DVT-Price-Sheet.png` — what Dryer Vent Tech pays Transcenlutions LLC (source: `pricesheet.html`)
- `Business-App-Builder-Prompt.md` — reusable prompt for the next company app

Repo is public during the build stage; switch to private (and host on Cloudflare Pages) before go-live.
